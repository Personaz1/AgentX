# AgentX — Archived Security Research Snapshot

> **Archive notice:** AgentX is a historical research repository containing command-and-control and remote-agent capabilities. It is not presented as a deployable security product.

## Historical scope
The codebase explored a controller/agent architecture, remote tasking, network communication, cryptographic transport, agent orchestration and LLM-assisted analysis. Some historical components are dual-use and can enable unauthorized access, surveillance, credential collection or evasion.

## Status
Archived research snapshot. No active maintenance, release assurance, compatibility guarantee or operational support is provided. This repository is not an endorsed C2 service and should not be deployed.

## Safety boundary
Do not execute or deploy agent capabilities for unauthorized access, persistence, evasion, credential theft, data exfiltration or disruption. Defensive study must be confined to isolated systems that you own or are explicitly authorized to test, using synthetic data and documented scope.

## Research-only reading
The source may be examined to understand historical architecture and identify defensive lessons. This README deliberately omits build, deployment and command instructions.
